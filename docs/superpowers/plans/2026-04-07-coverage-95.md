# Coverage 95% Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Increase overall test coverage from 89% to 95% by adding tests for uncovered lines, then bump `--cov-fail-under` to 95.

**Architecture:** Mix of real integration tests (renderer, DB, EXIF), API TestClient tests (regions, render routes), E2E subprocess tests (CLI wiring), and one unit test (styles). Every test targets specific uncovered lines. Final step bumps the coverage threshold.

**Tech Stack:** pytest, pytest-cov, FastAPI TestClient, subprocess, PIL/Pillow, SQLAlchemy (in-memory SQLite)

**Spec:** `docs/superpowers/specs/2026-04-07-coverage-95-design.md`
**Issue:** dalbrecht/Voyages#9

---

**Important context:**
- Current coverage baseline: 89% overall, 100% domain
- Target: 95% overall, 100% domain maintained
- Existing CI command: `make ci` (lint + fmt-check + test)
- Coverage threshold enforcement is the final step — update Makefile targets when bumping `--cov-fail-under` to 95
- E2E tests use `@pytest.mark.e2e` and are excluded from `make test`
- Existing test patterns: `_make_client()` for API, `session` fixture for DB, `@patch` for EXIF mocking, `subprocess.run` for E2E
